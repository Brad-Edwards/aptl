# Workshop walkthrough retired

The previous walkthrough depended on APTL-local `guided-purple` profile files
and the `techvault-attacker-target` reduced SDL. Those inputs are no longer
shipped, so its commands cannot establish a supported or qualified workshop.

Do not substitute the full acquired `techvault` pack: it has a different
content identity and surface. A replacement walkthrough must be published only
after its scenario owner releases a suitable bounded pack and the participant
profile is re-qualified against that exact pack identity.

For the supported full-range startup path, use the
[Quick Start](../getting-started/quick-start.md).
