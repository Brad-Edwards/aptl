# Workshop playbook retired

The previous facilitator playbook was bound to the retired APTL-local
`guided-purple` participant profile and `techvault-attacker-target` scenario.
APTL no longer ships either input, and the playbook must not be used as current
delivery or qualification guidance.

A successor workshop requires a separately authored, released bounded
environment pack plus new participant-profile and readiness evidence bound to
that pack's exact version and associated-artifact set digest. The full acquired
`techvault` pack is not an equivalent replacement.

See the [Quick Start](../getting-started/quick-start.md) for the supported
full-range operator path.
