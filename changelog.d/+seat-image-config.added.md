A seat image now describes itself. The resources its VM needs and the loopback endpoints its guest publishes travel with the image as a config blob rather than coming from a separately built release manifest, so the disk that boots and the declaration of how to boot it cannot drift apart. The declaration is bounded and fail-closed: an image asking for absurd resources, publishing a routable address, declaring the same audience twice, or omitting a participant endpoint is refused instead of launched.
