# Historical TechVault curated live validation evidence

This directory preserves the recorded 2026-06-24 and 2026-06-25 evidence for
four former APTL-local reduced TechVault SDLs. The evidence is historical: the
SDLs and their catalog aliases are retired and are not members of the acquired
`techvault` pack.

The committed `result.json`, `snapshot.json`, and participant-action record
remain available for design archaeology. Their old reproduction driver has
been removed because running it would select identifiers that APTL now rejects.
These records do not qualify the current full acquired pack and do not claim
golden-range maturity.

Current full-pack validation uses the same acquired `ScenarioBundle` for static
checks, realization expectations, runtime evidence, and exact pack identity.
See the [TechVault static gate](techvault-static-validation-gate.md) and
[TechVault live gate](techvault-live-validation-gate.md).
