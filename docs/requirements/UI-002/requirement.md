# UI-002: Minimal Lab Home Landing Page

## Statement

The web UI shall provide a lab home page showing lab state (running/stopped), active containers, scenario list as cards with difficulty badges, and a start/stop control.

## Rationale

The lab home provides the entry point for all web UI interactions.
