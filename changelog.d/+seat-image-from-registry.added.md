`aptl seat` can resolve the VM disk it boots from an OCI registry reference instead of a locally staged release directory. The disk is pulled over plain HTTPS with an anonymous registry token, so a seat host still needs only QEMU and no Docker daemon, and integrity is the registry's own content addressing: every blob is fetched by digest and rejected unless its bytes hash to that digest. Resolution is fail-closed — an ordinary container image, an index that does not select exactly one x86_64 manifest, and a reference that is ambiguous or malformed are all refused rather than booted.
