# Retired guided-purple participant profile

The APTL-local `guided-purple` version 1 manifest, readiness suite, narrative,
configuration, and asset lock were coupled to a reduced TechVault SDL that is
not present in the acquired pack. They are no longer shipped, materialized, or
registered as CLI defaults.

APTL deliberately does not reconstruct that SDL, describe it as acquired, or
bind the old profile to the full `techvault` pack. A future participant release
must consume a separately authored and released scenario identity, then publish
a new profile and qualification evidence against those exact bytes.

The strict participant-profile and appliance-release schemas remain available
for independently supplied release artifacts. Historical architecture records
describe the retired version 1 design; they are not current operator guidance.
